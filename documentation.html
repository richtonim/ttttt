Getting Started

NodeRefine provides a unified platform for diagnosing and optimizing AI workflows. This guide walks you through creating an account, generating an API key, and running your first workflow scan.

To begin, sign up for a NodeRefine account and navigate to Settings → API Keys to generate your first key. All API requests require authentication via the Authorization: Bearer nr_live_... header.

Authentication

NodeRefine uses API key authentication. Keys are prefixed with nr_live_ for production and nr_test_ for sandbox environments.

HTTP
GET /v1/workflows HTTP/1.1
Host: api.noderefine.help
Authorization: Bearer nr_live_your_api_key
Content-Type: application/json

Workflows API

The Workflows API lets you register, scan, and analyze AI pipelines. Key endpoints:

  • POST /v1/workflows — Register a new workflow
  • POST /v1/workflows/{id}/scan — Run a full pipeline scan
  • GET /v1/workflows/{id}/health — Get current health score
  • GET /v1/workflows/{id}/issues — List detected issues

Nodes API

Inspect individual nodes within a workflow for detailed diagnostics, execution history, and replay capabilities.

Webhooks

Configure webhooks to receive real-time notifications when issues are detected, scans complete, or optimization recommendations are generated.

SDKs

Official SDKs are available for Python (pip install noderefine), Node.js (npm install @noderefine/sdk), and Go (go get github.com/noderefine/sdk).

CLI Reference

Install the CLI globally with npm install -g @noderefine/cli. Run nr --help for the full command reference.

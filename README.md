# Mustly AI

Enterprise-grade AI automation and agentic workflow engine.

**Website:** https://mustly.in

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in the `dist/` directory, ready for static deployment.

## Pages

- `/` — Home
- `/platform` — Platform overview
- `/solutions` — Industry solutions
- `/infrastructure` — Infrastructure details
- `/contact` — Contact form
- `/pricing` — Pricing plans (whitelist required)
- `/login` — Login (whitelist required)
- `/register` — Register (whitelist required)

## Whitelist Access

Registration, login, and purchasing require whitelist access. Contact us or use an invitation code (e.g., `MUSTLY2026`).

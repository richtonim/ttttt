# Entropy — AI Vehicle Intelligence Platform

Official website for [entropy.autos](https://entropy.autos). A high-end, minimal brand site for Entropy's AI decision and vehicle data platform.

## Tech Stack

- Next.js 16 (App Router, static export)
- React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion + GSAP
- Geist font family

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

This generates a static site in `dist/` and packages it as `dist.zip` for direct deployment to any static host (Nginx, S3, Vercel, Netlify, etc.).

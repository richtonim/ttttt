# Substratum — AI Infrastructure Platform

Official website for [substratum.pro](https://substratum.pro).

## Tech Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS
- Framer Motion

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in `dist/` — deploy to any static hosting (Vercel, Netlify, Nginx, etc.).

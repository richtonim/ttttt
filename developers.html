Quick Start

Get up and running in three steps.

Install the SDK

pip install noderefine · npm install @noderefine/sdk · go get github.com/noderefine/sdk

Authenticate

Create an API key from your dashboard or use the CLI: nr auth login

Analyze

Connect your first workflow and receive diagnostics in seconds.

Terminal 
# Install CLI
npm install -g @noderefine/cli

# Authenticate
nr auth login

# Scan a workflow
nr workflows scan --id wf_prod_agent_v2

# Inspect a specific node
nr nodes inspect --workflow wf_prod_agent_v2 --node llm_parser

# Set up webhook
nr webhooks create --url https://api.example.com/hooks/nr \
  --events issue.detected,scan.completed
Python
from noderefine import Client
client = Client(api_key="nr_live_...")
scan = client.workflows.analyze("wf_id")
Node.js
import { NodeRefine } from '@noderefine/sdk';
const client = new NodeRefine({ apiKey });
const scan = await client.workflows.analyze('wf_id');
